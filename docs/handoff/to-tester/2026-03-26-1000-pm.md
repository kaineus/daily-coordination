## 다음 작업 지시

### F6 + F7 테스트 계획 수립

#### F6 RBAC 테스트 범위

**RLS 테스트**:
- admin 사용자 → clothing_categories INSERT/UPDATE/DELETE 성공
- user 사용자 → clothing_categories INSERT/UPDATE/DELETE 거부
- user_profiles: 본인 row만 SELECT 가능

**프론트 권한 테스트**:
- admin → 관리 메뉴 노출, /admin/categories 접근 가능
- user → 관리 메뉴 숨김, /admin/categories 직접 접근 시 리다이렉트
- 로그인 시 role이 authStore에 정상 저장

#### F7 카테고리 관리 테스트 범위

**CRUD**:
- 카테고리 추가: type 선택 + 이름/아이콘/온도범위/순서 입력 → 저장
- 카테고리 수정: 인라인 편집 → 저장 → DB 반영
- 카테고리 삭제: 확인 다이얼로그 → 삭제 → DB 반영
- 카테고리 삭제 (옷 있음): 경고 메시지 표시 + 재확인
- 상위분류 추가: type명 + 아이콘 입력 → 새 섹션 생성

**엣지 케이스**:
- 빈 이름으로 저장 시도
- 중복 이름 등록 시도
- 모든 카테고리 삭제 후 상태
