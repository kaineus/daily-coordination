## 다음 작업 지시

### 카테고리 관리 페이지 디자인

Admin 전용 페이지. 2depth(type > category) 아코디언 구조로 카테고리를 CRUD 관리.

#### 디자인 필요 화면

**1. 카테고리 관리 메인** (모바일 + 데스크톱)
- type별 아코디언 (펼침/접힘)
- 각 카테고리 행: 이름, 아이콘, 온도 범위, 순서, 편집/삭제 버튼
- "+ 카테고리 추가" 버튼 (각 type 섹션 내)
- "+ 새 상위분류 추가" 버튼 (하단)

**2. 인라인 편집 모드**
- 카테고리 행이 입력 폼으로 전환
- 저장/취소 버튼

**3. 삭제 확인 다이얼로그**
- 기본 삭제 확인
- 등록된 옷이 있을 때 경고 메시지 변형

**4. 관리 네비게이션**
- 기존 2탭(코디/옷장)에 admin일 때만 "관리" 탭 추가
- 또는 프로필/설정 영역에서 접근
