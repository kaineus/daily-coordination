## 다음 작업 지시

### F7 카테고리 관리 페이지 구현

#### 화면 구조

**모바일** (`screens/admin-categories.html`):
- 아코디언 패널: type별 펼침/접힘
- 카테고리 행: 아이콘 + 이름 + 메타(온도·순서) + 편집/삭제 버튼
- 인라인 편집: primary-fixed/20 배경, 입력 필드 + 저장/취소
- 삭제 다이얼로그: bottom sheet 스타일
- 하단 탭바: 3탭 (코디 / 옷장 / 관리) — admin일 때만 관리 탭 노출

**데스크톱** (`screens/admin-categories-desktop.html`):
- 아코디언 패널: type별, max-width 900px
- 카테고리: 5열 grid (이름 | 아이콘 | 온도 범위 | 순서 | 작업)
- 인라인 편집: grid 내에서 각 셀이 input으로 전환
- 삭제 다이얼로그: center modal, max-width 420px
- 상단 nav: 3탭 (코디 / 옷장 / 관리) — admin일 때만

#### 주요 컴포넌트

1. **Accordion Panel**: 펼침/접힘 토글, expand_more/chevron_right 아이콘
2. **Category Row**: 일반 모드 ↔ 편집 모드 전환
3. **Delete Dialog**: 기본 확인 vs 옷 있을 때 경고 변형 (error-container 배경)
4. **Admin Badge**: tertiary-fixed 배경, "ADMIN" 텍스트
5. **Add Type Button**: dashed border, "새 상위분류 추가"

#### 네비게이션 변경
- 기존 2탭 → admin role일 때 3탭으로 확장
- 라우트: `/admin/categories`
- admin 아닌 사용자가 직접 접근 시 메인 페이지로 리다이렉트
