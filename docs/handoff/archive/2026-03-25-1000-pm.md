### F4 구현 준비 (디자인 대기 중)

디자인이 나오기 전에 **백엔드(Edge Function) 먼저 구현** 가능합니다.

#### 1단계: Edge Function — `chat-register` (선행 가능)

새 Edge Function `supabase/functions/chat-register/index.ts` 생성:

**역할**: 사용자 자연어 입력 → Gemini로 카테고리/색상 파싱 → 구조화된 JSON 응답

**요청 형식**:
```typescript
POST /functions/v1/chat-register
{
  messages: [
    { role: "user", content: "검정 패딩이랑 베이지 니트 등록해줘" }
  ]
}
```

**응답 형식**:
```typescript
{
  message: "2개 등록할게요!",  // 사용자에게 보여줄 메시지
  items: [                     // 파싱된 아이템 (없으면 빈 배열)
    { categoryId: "uuid", categoryName: "패딩", categoryIcon: "🧥", color: "#333333", colorName: "검정" },
    { categoryId: "uuid", categoryName: "니트", categoryIcon: "🧶", color: "#F5E6D3", colorName: "베이지" }
  ],
  needsClarification: false,   // 되물어야 하면 true
  suggestions: []              // 되물을 때 선택지 목록
}
```

**Gemini 프롬프트 설계 핵심**:
- clothing_categories 전체 목록을 system prompt에 포함
- 색상 프리셋 13개 매핑 테이블 포함
- 복수 아이템 파싱 지원
- 불확실하면 `needsClarification: true` + `suggestions` 반환
- 대화 히스토리(`messages` 배열)로 멀티턴 지원

**참고**: 기존 `recommend/index.ts` 패턴 참고하여 동일 구조로 작성
