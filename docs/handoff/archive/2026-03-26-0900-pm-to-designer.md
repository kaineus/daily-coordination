## 다음 작업 지시

### 옷장 페이지 2depth 그룹 레이아웃 디자인

현재 옷장 페이지는 상위분류(type) 1depth로만 그룹화됨.
**type > category 2depth 계층**으로 변경 필요.

#### 변경 전 (1depth)
```
🧥 아우터 (3)
  [패딩 — 검정]  [코트 — 베이지]  [자켓 — 네이비]
```

#### 변경 후 (2depth)
```
🧥 아우터 (3)
  패딩 (2)
    [검정 패딩]  [네이비 패딩]
  코트 (1)
    [베이지 코트]
```

#### 디자인 필요 사항
1. **카테고리 서브헤더** — type 헤더와 아이템 사이에 들어갈 2depth 카테고리 라벨
   - 기존 `.group-name` (type 헤더)보다 작고 가벼운 스타일
   - 개수 표시 포함
2. **들여쓰기/계층 감** — 1depth ↔ 2depth 시각적 구분
3. **모바일 + 데스크톱** 양쪽 반영

#### 산출물
- `components.md` — Closet 섹션에 서브그룹 헤더 명세 추가
- `screens/closet-page.html` / `closet-page-desktop.html` 업데이트
