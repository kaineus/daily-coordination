### 1. F4 — 등록 모달 업데이트 디자인 (P1)

기존 `add-clothing-modal`의 상단에 자연어 입력 영역을 추가하는 디자인.

```
┌─ 옷 등록 ──────────────────────┐
│                                │
│  "검정 패딩 등록해줘" [전송]     │  ← AI 입력 영역
│                                │
│  ┌─ 파싱 결과 ──────────────┐  │
│  │ 🧥 패딩 · 검정  [확인]   │  │  ← 결과 카드
│  └──────────────────────────┘  │
│                                │
│  ─ 또는 직접 선택 ───────────  │  ← 구분
│                                │
│  [아우터] [상의] [하의] ...     │  ← 기존 수동 선택 UI
│  ...                           │
└────────────────────────────────┘
```

#### 디자인 요소
- 입력 필드 + 전송 버튼 (모달 상단)
- 파싱 결과 카드: 카테고리 아이콘 + 색상 도트 + 이름 + 확인/수정 버튼
- 복수 아이템 결과 리스트
- 되묻기 UI: 선택지 칩(Chip) 나열
- 등록 완료 피드백 (체크 애니메이션 등)
- "또는 직접 선택" 구분선 아래에 기존 카테고리/색상 선택 UI 유지

### 2. F5 — 코디 추천 스크랩 레이아웃 디자인 (P2)

현재 코디 추천 결과를 매거진 스크랩 스타일로 리디자인.

```
┌─ 오늘의 코디 ──────────────────┐
│                                │
│        [아우터 SVG]            │  ← 최상단, 살짝 기울기
│      네이비 패딩               │
│                                │
│       [상의 SVG]               │  ← 아우터 아래 살짝 겹침
│     베이지 니트                 │     (SVG만 겹치고 텍스트는 독립)
│                                │
│       [하의 SVG]               │
│     검정 슬랙스                 │
│                                │
│        [신발 SVG]              │  ← 최하단
│      브라운 부츠                │
│                                │
│  "따뜻하게 입으세요!" — AI      │
│                    [다른 코디]  │
└────────────────────────────────┘
```
* 악세서리(모자, 목도리 등)는 해당 아이템 옆에 보조 배치

#### 레이아웃 필수 규칙
1. **배치 순서는 실제 착장 순서**: 위→아래로 아우터 > 상의 > 하의 > 신발
2. **SVG끼리는 살짝 오버랩 OK** (스크랩 감성) — 단, 핵심 실루엣은 가리지 않기
3. **카테고리명 + 색상명 텍스트는 오버랩 영역 밖에 배치** — 항상 가독성 확보 (절대 가려지면 안 됨)
4. 악세서리는 메인 의류 흐름 옆에 자연스럽게 배치

#### 디자인 요소
- SVG 아이템들의 스크랩북 레이아웃 (자연스러운 기울기, 오버랩, 그림자)
- 아이템별 색상이 적용된 상태로 표시
- 기존 home-page의 추천 카드 영역 교체
- The Ethereal Boutique 톤 유지
