3. **옷장 페이지 진입점** — `docs/design/screens/closet-page.html` 헤더에 "AI 등록" 버튼 추가
4. **컴포넌트 명세** — `docs/design/components.md` 섹션 9~10 추가

### 디자인 주요 결정

- **진입점**: 옷장 페이지 헤더에 `primary-fixed` 배경의 "AI 등록" pill 버튼 (기존 "+" 버튼 왼쪽)
- **채팅 레이아웃**: 모바일은 전체화면 채팅, 데스크톱은 좌측 옷장 요약 + 우측 채팅 패널 split
- **AI 버블**: `surface-container-lowest` 배경 + `auto_awesome` 아바타 (primary-fixed 원형)
- **사용자 버블**: `primary` 배경, 우측 정렬
- **파싱 결과 카드**: 카테고리 이모지 + 색상 도트 + 이름, 체크 아이콘 포함
- **되묻기 UI**: pill 형태 Suggestion Chip, 카테고리 이모지 포함
- **등록 확인**: "등록하기" (primary) + "수정" (ghost) 버튼 쌍
- **성공 피드백**: 녹색 체크 pop-in 애니메이션 + 등록 완료 메시지
- **빠른 제안 칩**: 입력바 하단에 예시 문구 칩 ("검정 패딩", "베이지 니트" 등)
