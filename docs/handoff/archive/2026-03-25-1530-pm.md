## 배경
F4(자연어 옷 등록) + F5(AI 생성 이미지 코디) 기획 중.
옷 등록 시 Gemini 이미지 생성으로 의류 이미지를 만들고,
코디 추천 시 캐시된 이미지를 매거진 스크랩 스타일로 조합하려 함.

**구현 전에 이미지 생성 가능 여부를 먼저 검증해야 함.**

## 다음 작업 지시

### Gemini 이미지 생성 PoC (Proof of Concept)

아래 항목을 순서대로 검증하고 결과를 보고해주세요.

#### 1. API 가용성 확인
- Gemini API (현재 사용 중인 키)에서 이미지 생성이 지원되는지 확인
- `responseModalities: ["TEXT", "IMAGE"]` 설정으로 호출 가능한지
- 사용 가능한 모델: `gemini-2.0-flash` 등

#### 2. 프롬프트 테스트
아래 프롬프트로 의류 이미지 생성 품질 확인:
```
"A navy puffer jacket, flat lay photography on pure white background,
magazine cutout style, no mannequin, isolated garment,
high quality product photo, clean edges"
```
- 다른 카테고리도 테스트: 니트, 슬랙스, 운동화 등
- white background + flat lay + cutout 스타일이 일관되게 나오는지

#### 3. 실용성 평가
- 생성 속도 (옷 등록 시 허용 가능한 수준인지)
- 이미지 품질 및 스타일 일관성
- 비용 (프로토타입 수준에서 감당 가능한지)
- Supabase Storage에 저장하는 흐름 가능 여부

#### 4. 결과 보고
PoC 결과를 다음 형식으로 정리:
```
- API 지원 여부: O/X
- 모델명:
- 생성 속도: ~N초
- 이미지 품질: 상/중/하
- 스타일 일관성: 상/중/하
- 예상 비용: 건당 약 $X
- 결론: 진행 가능 / 대안 필요
```

생성된 샘플 이미지가 있으면 `docs/design/poc/` 에 저장해주세요.

### 참고
- 기존 Gemini Edge Function: `supabase/functions/recommend/index.ts`
- PoC는 로컬 스크립트로 빠르게 검증해도 됨 (Edge Function 필수 아님)
- 대안이 필요할 경우: Imagen 3 (Vertex AI), 무료 스톡 이미지 매핑 등도 검토
