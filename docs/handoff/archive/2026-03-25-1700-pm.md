### 2. 코디 추천 type 뎁스 표시 (P1, 즉시 가능)

현재 추천 결과가 "패딩 · 검정"만 표시 → "아우터 > 패딩 · 검정"으로 변경.

- 홈페이지 추천 카드에서 상위분류(type) 라벨 추가
- 데이터는 이미 category.type에 있으므로 UI 변경만 필요

### 3. F4 Edge Function — chat-register (P1, 선행 가능)

이전 핸드오프 내용 그대로 유효:
- `supabase/functions/chat-register/index.ts` 생성
- 자연어 → Gemini 파싱 → 카테고리/색상 JSON 응답
- 25개 색상 프리셋을 Gemini 프롬프트에 포함
- 프리셋에 없는 색상도 AI가 자유 hex 매핑 가능

### 4. F4 프론트엔드 (디자인 완료 후)

- 기존 모달 상단에 자연어 입력 필드 추가
- Designer가 `add-clothing-modal-v2` 완성하면 착수

### 5. F5 SVG + 스크랩 레이아웃 (F4 이후)

- SVG 에셋 수집 + 카테고리 매핑
