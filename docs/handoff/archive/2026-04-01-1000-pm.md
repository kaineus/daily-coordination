## 변경 사항
코드 점검 결과 에러 핸들링 누락이 다수 발견됨. 버그 위험(P0) + UX 개선(P1) 일괄 보강 요청.

## 다음 작업 지시

### P0 — 버그 위험 (필수)

#### 1. closet.service.js 세션 null 체크 추가
- `addClothing()`, `deleteClothing()`, `getUserClothes()` 에 세션 null 체크 누락
- 다른 서비스(`recommend.service.js`, `chat.service.js`)는 이미 아래 패턴 사용 중:
  ```js
  const { data: { session } } = await supabase.auth.getSession();
  if (!session) return { data: null, error: { message: '인증 필요' } };
  ```
- closet.service.js도 동일 패턴으로 통일

#### 2. fetch 응답 try-catch 추가
- `recommend.service.js`의 `getWeather()`, `getRecommendation()`
- `chat.service.js`의 `sendChatMessage()`
- `res.json()` 파싱 실패 시 uncaught rejection 발생 가능
- 패턴:
  ```js
  try {
    const res = await fetch(...);
    const data = await res.json();
    if (!res.ok) return { data: null, error: data };
    return { data, error: null };
  } catch (err) {
    return { data: null, error: { message: err.message } };
  }
  ```
