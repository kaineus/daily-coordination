### F4 + F5 테스트 계획 수립

#### F4 테스트 범위

**단위 테스트 (Edge Function `chat-register`)**:
- 단일 아이템: "검정 패딩" → categoryName: "패딩", color: "#333333"
- 복수 아이템: "베이지 니트랑 네이비 슬랙스" → 2개 items
- 되묻기 (카테고리 불명): "갈색 옷" → needsClarification: true
- 되묻기 (색상 누락): "패딩 등록해줘" → 색상 질문
- 존재하지 않는 카테고리: "한복" → 유사 제안
- 엣지 케이스: 빈 입력, 무관한 입력, 오타

**통합 테스트**:
- chat-register 파싱 → addClothing 등록 흐름
- 멀티턴 대화: 되묻기 → 응답 → 등록 완료

**E2E (디자인/구현 완료 후)**:
- E2E-F4-01: 모달 내 자연어 입력 → 단일 등록 → 옷장 반영
- E2E-F4-02: 복수 아이템 등록 → 모두 반영
- E2E-F4-03: 되묻기 → 칩 선택 → 등록
- E2E-F4-04: 자연어 입력 후 수동 선택으로 전환 (양쪽 공존 확인)

#### F5 테스트 범위

**컴포넌트 테스트**:
- SVG 매핑: 30개 카테고리 모두 SVG 존재 확인
- 색상 적용: hex 색상이 SVG fill에 정확히 반영
- 폴백: SVG 없는 카테고리 → 이모지 폴백 동작

**E2E**:
- E2E-F5-01: 코디 추천 → 스크랩 레이아웃으로 표시
- E2E-F5-02: 다양한 색상 조합에서 SVG 색상 정확성
