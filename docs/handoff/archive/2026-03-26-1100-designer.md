## 변경 사항
- F2 옷장 페이지: 1depth → **2depth 그룹 표시** (type > category)
- 모바일 + 데스크톱 양쪽 반영 완료

## 다음 작업 지시

### 옷장 2depth 그룹 레이아웃 구현

#### 변경 전 (1depth)
```
🧥 아우터 (3)
  [패딩 — 네이비]  [코트 — 베이지]  [자켓 — 블랙]
```

#### 변경 후 (2depth)
```
🧥 아우터 (3)
  패딩 (2)
    [검정 패딩]  [네이비 패딩]
  코트 (1)
    [베이지 코트]
```

#### 디자인 명세

**Category Subheader (2depth)**:
- 폰트: 모바일 12px semibold / 데스크톱 13px semibold
- 색상: `on-surface-variant`
- 들여쓰기: `pl-3` (12px)
- 개수 표시: 모바일 10px / 데스크톱 11px, `outline` 색상
- 서브그룹 간 간격: 모바일 `mb-4` / 데스크톱 `mb-6`

**아이템 카드 표시명 변경**:
- 기존: 카테고리명만 (예: "패딩")
- 변경: 색상명 + 카테고리명 (예: "검정 패딩")
- 서브헤더에 카테고리명이 있으므로, 카드에서는 색상으로 구분

#### 수정 대상
1. `src/utils/closet-grouping.js` — `groupByCategory()` 반환 구조에 2depth 추가
2. `src/components/pages/closet-page.js` — 렌더링에서 2depth 반영
   - type 헤더 → category 서브헤더 → 아이템 카드

#### 주의사항
- 기존 `groupByColor` 동작은 변경 없음
- 데스크톱 필터 칩 (type 필터) 동작 유지
- 아이템 카드 들여쓰기 `pl-3`은 서브헤더와 동일 레벨
