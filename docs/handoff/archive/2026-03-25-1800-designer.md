### F4 구현 (이전 핸드오프와 다른 점만)
1. **탭 UI 삭제** — 탭 전환 컴포넌트 불필요
2. **모달 구조**: 상단에 AI 입력 필드(항상 표시) → 구분선 → 하단에 기존 수동 선택 폼
3. AI 파싱 결과는 입력 필드 아래에 인라인 표시 (별도 화면 전환 없음)
4. 나머지(Edge Function, addClothing 재사용 등)는 이전 핸드오프와 동일

### F5 구현 (이전 핸드오프와 다른 점만)
1. **레이아웃 방향**: 수직 (flex-col, space-y-[-16px])
2. **아이템 교차 배치**: 홀수(아우터/하의) → 좌측 카드 + 우측 텍스트, 짝수(상의/신발) → 우측 카드 + 좌측 텍스트
3. **텍스트 독립 영역**: 카드와 텍스트를 flex row로 배치, 텍스트가 SVG 오버랩 영역에 겹치지 않도록
4. 기존 home-page의 "오늘의 코디" 섹션 전체를 스크랩 레이아웃으로 교체
