### 1단계: F6 — RBAC 기본 세팅

#### DB
1. `user_profiles` 테이블 생성 (migration)
   - `id` uuid PK FK → auth.users.id
   - `role` text default 'user' check ('user', 'admin')
   - `created_at` timestamptz default now()
2. 트리거: auth.users INSERT 시 user_profiles 자동 생성 (role = 'user')
3. RLS 정책:
   - user_profiles: 본인 row만 SELECT
   - clothing_categories: SELECT는 전체 허용, INSERT/UPDATE/DELETE는 admin만

#### 프론트
1. authStore에 `role` 필드 추가
2. 로그인 시 user_profiles에서 role fetch → store 저장
3. 라우터에 admin 가드 추가 (`/admin/*` → role !== 'admin'이면 리다이렉트)
4. 네비게이션에 "관리" 메뉴 조건부 노출 (admin만)

### 2단계: F7 — 카테고리 관리 페이지

#### 라우트
- `/admin/categories`

#### UI 구조 (아코디언 + 인라인 편집)
- type별 아코디언 섹션 (펼침/접힘)
- 각 카테고리: 이름, 아이콘, 온도 범위, 순서 표시
- 편집 버튼 → 인라인 편집 모드
- 삭제 버튼 → 확인 다이얼로그 (등록된 옷 있으면 경고)
- 각 type 섹션에 "+ 카테고리 추가" 버튼
- 하단에 "+ 새 상위분류 추가" 버튼

#### 서비스
- `admin.service.js` 신규: createCategory, updateCategory, deleteCategory, createType
- 기존 `closet.service.js`의 getCategories() 재사용 (조회)
