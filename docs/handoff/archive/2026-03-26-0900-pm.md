## 다음 작업 지시

### F2 옷장 2depth 그룹 표시

현재 옷장 페이지는 **type(상위분류)** 1depth로만 그룹화되어 있음.
**type > category 2depth 계층**으로 변경 필요.

#### 현재 (1depth)
```
🧥 아우터 (3)
  패딩 — 검정  |  코트 — 베이지  |  자켓 — 네이비
```

#### 변경 후 (2depth)
```
🧥 아우터 (3)
  패딩 (2)
    검정 패딩  |  네이비 패딩
  코트 (1)
    베이지 코트
```

#### 수정 대상
1. **`src/utils/closet-grouping.js`** — `groupByCategory()` 반환 구조에 2depth 추가
   - 각 type 그룹 내에서 `category.name`으로 재그룹
2. **`src/components/pages/closet-page.js`** — 렌더링에서 2depth 반영
   - type 헤더 → category 서브헤더 → 아이템 목록

#### 주의사항
- 기존 `groupByColor` 동작은 변경 없음
- 데스크톱 필터 칩 (type 필터) 동작은 유지
- 카테고리 내 아이템이 1개뿐이면 서브헤더가 과할 수 있음 → 카테고리명은 간결하게 표시
