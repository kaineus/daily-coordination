## Gemini 모킹 전략

Edge Function 테스트에서 Gemini API를 직접 호출하지 않는다.
구현 시 파싱 로직과 Gemini 호출을 분리해야 테스트 가능:

```
[사용자 입력] → [프롬프트 구성] → [Gemini 호출] → [응답 파싱] → [결과 반환]
                                    ↑ 모킹 지점
```

- **프롬프트 구성 함수**: 순수 함수로 테스트 가능
- **응답 파싱 함수**: Gemini JSON 응답을 표준 형식으로 변환 — 순수 함수
- **Gemini 호출**: 모킹으로 대체
